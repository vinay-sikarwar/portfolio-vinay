# Vinay Sikarwar - Portfolio

Personal portfolio website for **Vinay Sikarwar**, Software Developer specializing in the MERN stack and problem solving.

## Tech Stack

- **React 19** & **TypeScript**
- **Vite** for fast modern bundling
- **Framer Motion** & **Canvas 3D** (Sakura falling leaf physics)
- **Lucide Icons**

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
